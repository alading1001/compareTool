# Windows 文件夹扫描优化验证（2026-09-25）

本轮在第一批 Git 批量读取、相似文本渲染优化的基础上，处理目录扫描的重复工作。

## 已落地内容

- Windows 链接类型判断复用一次 `lstat` 中的类型与 reparse tag。
- 文件身份查询复用同一次安全打开得到的初始句柄身份；内容读取前后仍重新查询身份。
- 捕获和复核中的叶文件检查交给紧随其后的安全打开；目录进入前仍检查链接。
- 单个任务缓存比较根的真实路径，目标文件真实路径每次重新解析。
- 根缓存保留路径大小写，避免把大小写敏感目录中的 `old` 和 `OLD` 合并。
- 没有修改 `file_exporter.py`，没有删除源树最终复核或输出事务校验。

## 本机对照结果

300 个文件/端，每文件 80 行，其中 30 个修改。修改前后交替各运行三次。
计时只包含扫描、内容比较、变更文件快照及源树最终复核，不含完整报告与交付事务。

| 本轮优化后 | 1.6865 / 1.7072 / 2.4393 | 1.7072 |

前后变更清单核对正确，全部变更端点快照的完整字节已核验，摘要一致。
