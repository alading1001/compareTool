## D1 与 D2 的取舍

保留 MAX_* = None 的显式策略接口，以及一次性 Git 读取、公共 ArchiveVCS
动态 setter、GNU sparse 提取等兼容路径。它们不能因默认未启用就当成死代码。
本轮没有新增通用策略框架，也没有将默认关闭的性能限制重新启用。

事务扫描分布在不同状态边界：

| 阶段 | 保护的对象与原因 |
| --- | --- |
| 生成前目标基线 | 固定任务开始时旧产物，防止慢任务覆盖更新输出 |
| 锁内目标复核及 stage 身份 | 恢复后重新核对目标，并与递归分析前的 stage 基线绑定 |
| 旧目标移至备份 | 移动前校验旧目标，移动后校验实际被移动的对象 |
| stage 安装 | 安装前校验 stage，安装后复核最终目标中的对象 |
| commit 后清理备份 | 验证备份，移入隔离路径后验证，再按恢复协议删除 |

实际入口：`prepare_target_states`、`_replace_outputs_locked`、
`_move_verified`、`_delete_verified`、`_finish_quarantine_delete`。
路径在移动前后可能指向不同对象，不能用 path/size/mtime 跨阶段缓存摘要。
A5 只减少每个节点同一遍处理中重复的 lstat，没有删除上述任何内容扫描阶段。
