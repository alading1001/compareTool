# 外置排除文件的简化界面

手工文本框始终可编辑。界面提供“追加外置排除规则”的勾选、文件路径、“选择文件”和“清空文件”。只有勾选并选好文件后才展开只读内容；取消勾选立即隐藏预览、保留路径。清空文件会取消勾选、移除路径并隐藏内容，不修改磁盘文件或手工规则。

选择文件仅记住路径，勾选后才与手工规则合并、去重，任意一条命中就排除。关闭只用手工内容，路径继续按项目保存；切换项目、重启和多项目任务编辑会恢复各自设置。每次生成读取启用文件的最新内容，同步预览，整批同一文件只读一次。

合并仅对去除行首尾空白后的相同规则文本去重，保留手工在前的顺序及大小写。手工 `#` 是字面字符；文件忽略空行和 `#` 整行注释。外置内容先严格 UTF-8/BOM、失败后严格 GB18030，不要求选择编码。启用文件读取失败不会少用规则继续；未启用时不读取文件、不显示预览，手工规则仍可比较。合同见 [排除规则贯穿流程](report-and-export-contract.md#排除规则贯穿流程)。

旧版已添加任务保持原规则范围，编辑后使用新设置。旧文件模式保存在手工字段里的预览不会被转成永久手工规则，避免关闭外置文件后旧预览仍然参与排除。
