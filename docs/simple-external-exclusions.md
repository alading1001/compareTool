# 外置排除文件的简化界面

手工文本框始终可编辑。新增操作只有“使用外置排除文件”的勾选、文件路径和“选择文件”按钮；选中后直接显示只读文件内容及已启用/未启用状态，没有编码、模板、试匹配或快照模式控件。未选文件时隐藏文件内容区。

选择文件仅记住路径，勾选后才与手工规则合并、去重，任意一条命中就排除。关闭只用手工内容，路径继续按项目保存；切换项目、重启和多项目任务编辑会恢复各自设置。每次生成读取启用文件的最新内容，同步预览，整批同一文件只读一次。

合并仅对去除行首尾空白后的相同规则文本去重，保留手工在前的顺序及大小写。手工 `#` 是字面字符；文件忽略空行和 `#` 整行注释。外置内容先严格 UTF-8/BOM、失败后严格 GB18030，不要求选择编码。启用文件读取失败不会少用规则继续；未启用文件的预览读取问题不阻止手工比较。合同见 [排除规则贯穿流程](report-and-export-contract.md#排除规则贯穿流程)。

旧版已添加任务保持原规则范围，编辑后使用新设置。旧文件模式保存在手工字段里的预览不会被转成永久手工规则，避免关闭外置文件后旧预览仍然参与排除。
